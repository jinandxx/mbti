# 내 안의 빌런 찾기

`index.html`을 브라우저에서 열면 바로 실행됩니다. 설치, 외부 라이브러리, 서버, 데이터베이스가 필요하지 않습니다.

- `index.html`: 시작 / 질문 / 결과 화면
- `style.css`: 모바일·데스크톱 반응형 디자인
- `data.js`: 16개 질문, 16가지 유형별 콘텐츠
- `script.js`: 진행, 점수 계산, 저장, 공유, PNG 다운로드
- `test.cjs`: 개발용 검증 (`node test.cjs`)

기획안의 빌런 콘셉트를 유지하고, 요청에 맞춰 12문항을 16문항으로 변경했습니다. 각 지표는 4문항이며 2:2 동점이면 해당 지표의 첫 답변을 따릅니다. 이는 공식 심리검사가 아닌 오락용 분류 규칙입니다.

진행 기록은 현재 브라우저의 localStorage에만 저장됩니다. 브라우저가 저장을 차단하면 현재 화면에서 계속 진행할 수 있습니다.

결과 공유는 지원되는 환경에서 기기 공유 메뉴를 사용하며, 그 외에는 문구 복사 또는 수동 복사를 제공합니다. 로컬 파일로 실행하면 다른 사람이 열 수 있는 공개 URL이 없으므로 결과 문구만 공유합니다. 웹에 올린 경우에는 테스트 링크도 함께 포함합니다. PNG 카드는 브라우저 Canvas로 생성합니다.
